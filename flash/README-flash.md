# Balong E5372 — прошивка ядра Linux 3.10

Готовый пакет для заливки ядра-3.10 на модем E5372 (платформа Balong hi6920cs).
Прошивщик взят у forth32 (balongflash, GNU GPLv3, https://github.com/forth32/balongflash).

## Состав

| Файл | Назначение |
|---|---|
| `balong_flash.exe` | прошивщик (Windows 32-bit, Rust3028 build) |
| `fw\05-00000105-Kernel_R1.fw` | компонент раздела Kernel: стоковый заголовок `55 AA 5A A5` + наш zImage (PAGE_OFFSET 0xC0000000, PHYS_OFFSET 0x33F00000), подпись сохранена |
| `flash-kernel.bat` | скрипт: заливка ТОЛЬКО ядра (остальные разделы не трогаются) |
| `flash-full.bat` | скрипт: заливка полного образа (`port\E5372_Update_21.290.23.00.00_kernel-3.10.bin`, webui-мод 1.5.2 без проверки подписи) |

## Как пользоваться (Windows)

1. Модем в GODLOAD:
   - выключить питание;
   - держать **MENU**, подключить питание;
   - на экране «Force Download» ещё раз **MENU**;
   - (альтернатива по терминалу: `AT^GODLOAD`).
2. В «Диспетчере устройств» найти COM-порт модема (появляется в GODLOAD).
3. Дважды кликнуть `flash-kernel.bat` и ввести номер COM-порта.
4. Дождаться перезагрузки устройства.

Ручные команды (что делают скрипты):
```
balong_flash.exe -p9 -n fw\                      (ядра-компонент из папки)
balong_flash.exe -p9 -m ..\port\E5372_Update_..._kernel-3.10.bin   (полный)
```

## Полезные опции balong_flash
- `-gl` — список флэш-регионов устройства, `-gd` — дамп региона;
- `-k` — без записи, только проверка подписи;
- `-f` — писать даже при ошибке CRC в журнале;
- `-r` — восстановить ранее сохранённую копию;
- `-d0..7` — выбор режима загрузчика (DLOAD_ID), `-dl` — список.

## Восстановление
Ядро-сток лежит в `..\stock_firmware\unpacked\05-00000105-Kernel_R1.fw`.
Кладём его в папку, например `fw-stock\`, и из GODLOAD:
```
balong_flash.exe -p9 -n fw-stock\
```

## Важно
- Это кастомное ядро 3.10: периферийные драйверы пока на stub'ах
  (serial/консоль, таймер, flash, wifi не портированы). После заливки
  возможен «тихий» старт без вывода и без shell — будет видно по первому
  живому логированию. Для восстановления рабочего устройства — см. выше.
- Согласно автору мода: работают только разлоченные (mod) версии,
  «signal! toga!» — прошивка идёт на свой риск, до «кирпича» включительно.
